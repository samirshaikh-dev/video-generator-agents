# meelTe 25-Second Social Reels Campaign

This folder contains **6 distinct, customer-friendly 25-second Reel scripts** created from the meelTe Advertisements guide. Each script is tailored for quick social consumption (Instagram Reels, YouTube Shorts, WhatsApp Status) with zero technical jargon, fast timing (summing to exactly 25 seconds), clear visual direction, and canonical meelTe brand guidelines.

## Universal Standards Used
- **Duration**: Exactly 25 Seconds per Reel.
- **Voiceover Pacing**: 50–60 words spoken at a warm, natural ~2.3 words/sec.
- **Brand Consistency**:
  - Exact brand name casing: **`meelTe`**
  - Primary palette: Dominant Orange (`#FEA711`) + Purple (`#743BAA`) with Lavender (`#F4EFFD`) and Charcoal (`#171923`).
  - Voice: Friendly, practical, celebratory of local shop owners, zero developer or tech jargon.
